Informações do sistema

Clientes usam a API PessoaEndereco; catálogos usam a API Categorium e seus itens; atendimentos usam a API Atendimento. O Swagger recebido não documenta rotas de funcionário nem de estoque/entrada: esses dois módulos continuam demonstrativos no navegador. No atendimento, o ID do funcionário precisa existir previamente na tabela funcionario do MySQL.
