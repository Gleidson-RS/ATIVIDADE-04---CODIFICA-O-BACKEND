Informações do sistema

Clientes usam a API PessoaEndereco; categorias, produtos e serviços usam as APIs Categorium, ProdutoItem e Servico; funcionários usam a API Funcionario; pedidos e atendimentos usam Atendimento e Pedido; o estoque usa Estoque. Os dados são gravados no MySQL. Pedidos de produtos dão baixa automática no estoque, e cancelar um pedido devolve as quantidades.
